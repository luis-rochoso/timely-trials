My first attempt at a platformer game. Doing it mostly for learning!

### Building
CMake is needed to build this project.
**Build** at the root directory of the project with:
```
cmake -S . -B build
```

### Compiling and running
After building, you must compile the game:
```
cmake --build build
```
After compilation, you can run it using:
```
./build/timelyTrials
```
